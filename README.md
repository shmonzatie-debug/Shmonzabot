# @shmonza2bot — пакет для загрузки с iPhone

## Что внутри
- `bot.py` — Telegram-бот, меню, команды, поиск Wikipedia, импорт/выгрузка отчётов.
- `storage.py` — SQLite-база пользователей и Sherlock-отчётов.
- `antispam.py` — ограничение частоты сообщений.
- `requirements.txt`, `Procfile`, `railway.json` — запуск на Railway.
- `sherlock_report_example.txt` — пример формата отчёта, не реальные данные.

## Импорт Sherlock report
1. Запусти Sherlock отдельно и сохрани результат в текстовый файл `.txt`.
2. В Telegram отправь этот файл своему боту.
3. В подписи к файлу напиши `/sherlock username` (замени username на имя, которое проверялось).
4. Импортировать и просматривать отчёты может только администратор, чей Telegram ID добавлен в `ADMIN_IDS`.
5. `/reports` показывает последние отчёты, `/report ID` отправляет сохранённый файл обратно.

Бот не запускает Sherlock автоматически. Он хранит уже сформированные текстовые отчёты. Сохраняй только отчёты, которые имеешь право обрабатывать; результаты наличия username на сайте не подтверждают личность владельца.

## Загрузка с iPhone
1. Скачай ZIP-архив на iPhone.
2. В приложении «Файлы» открой «Загрузки» и нажми на ZIP — iOS распакует его в папку.
3. Для загрузки в GitHub открой Safari и войди на GitHub.
4. Создай **Private repository** с названием `shmonza2bot`.
5. В репозитории нажми **Add file → Upload files** и выбери файлы из распакованной папки. Загружай содержимое папки, а не ZIP целиком. Не загружай `.env` с секретами.
6. На Railway выбери Deploy from GitHub repo.

## Переменные Railway
- `BOT_TOKEN` — токен из BotFather.
- `ADMIN_IDS` — твой числовой Telegram ID.
- `DATABASE_PATH` — `data/bot.sqlite3`.
- `LOG_LEVEL` — `INFO`.

Для постоянной базы подключи Railway Volume и смонтируй в `/app/data`. Если база нужна надёжная для долгого хранения, лучше перейти на PostgreSQL.

## Команды
- `/start`
- `/search запрос`
- `/reports` — список отчётов (админ)
- `/report ID` — скачать отчёт (админ)
- `/admin`
- `/help`
- `/cancel`

Не публикуй токен Telegram-бота и не добавляй его в GitHub.
